# PRD (쉽게 읽는 버전) — movensys-monopoly

> 이 문서는 기술 세부가 적고, **"무엇을 만드는지"** 를 비개발자도 이해할 수 있게 풀어 쓴 버전이다.
> 원문: [`PRD.md`](./PRD.md)

---

## 한 줄 요약

**사람 1명과 로봇팔 1대가 실제 모노폴리 보드로 같이 놀 수 있게 해주는 웹 서비스**를 만든다.
단, **AI도 로봇도 없이도 보드 1/2/3 전부가 완전히 돌아가도록** 설계하는 것이 핵심 원칙이다.

---

## 가장 중요한 설계 원칙 — "AI·로봇 없이도 끝까지 돌아간다"

우리가 **직접 만들지 않고 남에게 받아야 하는 것은 딱 3개의 FastAPI 서비스**다.

1. **Whisper AI (FastAPI)** — 말소리 → 글자
2. **Gemma 4 (FastAPI)** — 글자·보드 사진 → "게임에서 뭘 할지" 결정
3. **주사위 굴림 & 말 옮기기 (FastAPI)** — 로봇팔이 실제로 주사위를 굴리고 말을 옮기는 함수

이 3개는 **전부 없어도** 게임이 돌아간다. 수동 UI 버튼이 같은 역할을 대신하기 때문이다.

즉 본 패키지는 다음 3층 구조로 만든다.

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│  의도 입력      │──▶│   게임 엔진      │──▶│  물리 실행       │
│  (뭘 할지 정함) │   │   (규칙 그 자체) │   │  (실제 움직임)   │
│                 │   │                 │   │                 │
│ · Whisper+Gemma │   │ · 돈/땅/건물/   │   │ · 주사위·말     │
│   (없어도 됨)   │   │   임대료/감옥 등│   │   옮기기 API    │
│ · 수동 버튼     │   │ · 이건 우리가   │   │   (없어도 됨)   │
│   (항상 있음)   │   │   전부 만듦     │   │ · 애니만 재생   │
└─────────────────┘   └─────────────────┘   └─────────────────┘
```

**가운데(게임 엔진)는 AI·로봇과 완전히 독립**이다. 보드 1/2/3의 모든 규칙이 여기 들어간다.

---

## 그림으로 보는 전체 구조 (외부 FastAPI 3종 버전)

```
   ┌─────────────┐   음성    ┌──────────────────┐   글자   ┌──────────────────┐
   │    사람     │ ───────▶ │ Whisper FastAPI  │ ───────▶ │  Gemma 4 FastAPI │
   │             │  (말)     │   (받아씀)        │           │   (받아씀)        │
   └─────────────┘           └──────────────────┘           └─────────┬────────┘
                                                                      │ REST 호출
                                                                      ▼
   ┌────────────────────────────────────────────────────────────────────────┐
   │             movensys-monopoly FastAPI (본 프로젝트 — 우리가 만듦)         │
   │                                                                         │
   │   · 게임 규칙 엔진 (Board 1/2/3 전부) — AI/로봇 없이도 완전 동작         │
   │   · 돈/땅/건물/임대료/감옥/역/세금 등 모든 계산                          │
   │   · 보드 UI · 수동 컨트롤 패널 · 카메라 영상 표시                        │
   └──────────────────────────────┬──────────────────────────────────────────┘
                                   │ REST (선택적)
                                   ▼
                     ┌──────────────────────────────┐
                     │  주사위 굴림 & 말 옮기기       │
                     │        (FastAPI, 받아씀)       │
                     │  · POST /dice/roll → {value}  │
                     │  · POST /horse/move           │
                     └──────────────────────────────┘
```

- **왼쪽(사람 쪽):** Whisper가 말을 글자로 바꾸고, Gemma 4가 "무엇을 해야 할지" 결정한다.
- **가운데(본 프로젝트):** 결정에 따라 보드 화면/돈/건물 상태를 업데이트한다. **여기가 전부**다.
- **오른쪽(로봇):** "주사위 굴림 & 말 옮기기" FastAPI 서비스를 필요할 때 호출한다. 로봇이 없어도 수동 입력·화면 애니메이션으로 대체.

## 우리가 만드는 것과 받는 것

### ✅ 우리가 직접 만드는 부분
1. **보드 화면** — 모노폴리 판이 웹으로 보이는 UI (보드 1/2/3)
2. **돈 표시** — 지폐 그림 + 숫자 + 이동 애니메이션
3. **Property 관리** — 누가 어떤 땅을 가졌는지, 건물 수, 저당 여부
4. **게임 규칙 엔진** — **보드 2 풀 규칙 전부 포함** (감옥/역/유틸리티/세금/색상 독점/커뮤니티체스트)
5. **수동 컨트롤 패널** — AI·로봇 없이도 게임을 끝까지 진행할 수 있는 UI 버튼들
6. **카메라 화면** — 로봇에 달린 카메라 영상을 웹에 띄우기 (기존 `movensys_vlm`에서 복사, 없어도 게임 진행 가능)
7. **외부 FastAPI 어댑터** — 아래 3개 서비스를 얇게 감싸는 클라이언트

### ❌ 다른 팀에게서 받을 FastAPI 3개 (전부 선택적, 없어도 동작)
1. **Whisper AI on FastAPI** — 음성 → 글자
2. **Gemma 4 on FastAPI** — 글자·사진 → 게임 의도
3. **주사위 & 말 pick-and-place on FastAPI** — 실제 로봇팔이 주사위 굴리고 말 옮기는 함수
4. (선택) **Isaac Sim** — chance 카드 물리 소환

**중요:** 전에 PRD에 있었던 "movensys_vlm의 MoveIt2를 직접 호출한다"는 **없어졌다**. 로봇과의 접점은 3번 FastAPI 하나로만 수행한다.

## property 카드와 chance 카드 이미지는 어디서?

실제 Hasbro 모노폴리의 카드 디자인은 저작권이 있다. 그래서 3가지 옵션이 있다:

1. **오픈소스 리메이크 에셋 쓰기** — GitHub/Wikimedia에 공개된 것 찾기
2. **우리가 간단하게 그리기** — 색 띠 + 가격표만 있는 단순한 SVG
3. **원본 공용 자료 쓰기** — 라이선스가 허용되는 부분만

**추천:** (2)로 시작하고, 여유 생기면 (1)로 교체.
Chance/Community Chest 카드는 **텍스트만 있어도 규칙은 돌아간다**. 그림은 나중에 추가해도 된다.

## 게임은 이런 식으로 흘러간다 (AI 있든 없든 같은 경로)

모든 단계는 "AI 모드"와 "수동 모드"의 **동일 엔드포인트**를 쓴다. 다른 팀의 FastAPI가 없으면 UI 버튼이, 있으면 AI가 눌러준다.

### 1단계: "게임 시작"
- **AI 모드:** 사용자 발화 → Whisper → Gemma → `/api/game/start` 호출
- **수동 모드:** UI "게임 시작" 버튼이 `/api/game/start` 직접 호출
- 본 서버는 `GameState` 초기화, 턴을 사용자로 설정

### 2단계: "로봇 베이스 자세" (선택)
- 로봇 FastAPI가 있으면 거기에 호출. 없으면 건너뜀.
- **게임 상태 전이는 어느 쪽이든 독립적으로 진행**한다.

### 3단계: "주사위 굴려"
- 본 서버가 `dice_source` 설정에 따라 분기:
  - `robot`: 외부 FastAPI `/dice/roll` 호출 → 실제 값 받음
  - `manual`: UI에서 숫자 직접 입력
  - `rng`: 서버가 랜덤 생성 (개발 기본값)

### 4단계: "말 이동"
- **서버가 주사위 값대로 게임 상태를 즉시 갱신**한다 (로봇 응답을 기다리지 않음)
- 로봇 FastAPI가 있으면 동시에 `/horse/move`로 물리 이동 요청. 없으면 화면 애니메이션만.

### 5단계: 도착한 칸 처리 (서버가 스스로 결정)
본 서버는 `GameState`를 단일 진실 원천으로 갖고 있으므로 **AI 판독 없이도** `to_tile`을 이미 알고 있다.

#### 🟦 빈 땅(아무도 안 산 곳)
- 화면에 property 카드 모달
- "이 땅 살 돈이 있나?" 자동 검사 → 없으면 자동 패스
- 있으면 수동 모드에서는 **"스킵 / 구매 / 구매+건물 N채"** 버튼 즉시 제공. AI 모드는 동일 엔드포인트를 AI가 호출.
- 결정은 동일 엔드포인트 `/api/properties/{id}/decide`로 수렴

#### 🟥 상대방 땅
- 임대료 자동 차감 (돈 이동 애니메이션)
- 색상 그룹 독점 시 임대료 2배 자동 적용 (Board 2)
- 돈 부족 시 자동 매각 후보 제시 → 그래도 부족하면 **패배**

#### 🟨 Chance / Community Chest (Board 2)
- 카드 JSON 덱에서 랜덤 뽑기 → **효과 필드가 구조화돼 있어 서버가 바로 적용**
- Gemma 4가 카드 텍스트를 "해석"할 필요 **없음**
- Isaac Sim에 카드 소환 요청은 외부 영역

#### 🔒 감옥 (Board 2)
- 감옥행 타일 / 더블 3연속 / 카드로 투옥
- 탈출 방법: 더블 굴리기 / $50 지불 / 감옥 탈출 카드 사용 / 3턴째 자동 지불
- 수동 UI에서 세 탈출 버튼 제공

#### 🚂 역, 💡 유틸리티, 💰 세금 (Board 2)
- 역: 보유 개수별 임대료 ($25 × 2^(n-1))
- 유틸리티: 주사위 합 × 4 또는 × 10
- 세금 타일: 고정 금액 차감
- 전부 서버 쪽 순수 계산

## 돈을 어떻게 보여줄지

- 화면 위쪽에 두 플레이어 잔액을 **지폐 그림 + 숫자**로 항상 띄움
- 돈 감소: 지폐 떨어지며 페이드아웃
- 돈 증가: 지폐 날아들어오며 숫자 카운트업
- 사이드 토글로 최근 거래 내역 표시

---

## Property를 어떻게 보여줄지

- 화면 **좌/우 사이드바**에 각자 가진 땅을 **색상별로** 썸네일
- 썸네일 클릭 → 카드 모달 (가격/임대료표/건물 수/저당 여부)
- 건물 수는 썸네일 위 집 아이콘 개수로 표시

## 실행 방법

```bash
cd ~/workspaces/movensys-intelligence/movensys-monopoly/docker
docker compose down
docker compose build
docker compose up
```

브라우저에서 `localhost:8000` 열기.

**환경변수는 전부 비워도 된다.** 비어있으면 stub 모드로 기동되고, UI 상단에 `AI: off / Robot: off` 배지가 표시되며 수동 컨트롤이 활성화된다.

```bash
# 선택: 외부 FastAPI 연결
export STT_SERVICE_URL=http://whisper-service:8001
export LLM_SERVICE_URL=http://gemma-service:8002
export ROBOT_SERVICE_URL=http://robot-service:8003
```

## 컨펌이 필요한 것들

**Board 1 (짧은 버전)에 넣을 제안:**
- 세금 타일 1개
- 파킹 타일 1개
- 시작점 지날 때 +$100
- 구매 가능한 땅 8~10개

**Board 2 (원본 풀버전)에 넣을 제안 — 전부 자체 구현:**
- 감옥 시스템 (3턴 안에 탈출, 수동 버튼으로도 조작 가능)
- 역(railroad) 4곳 — 보유 개수별 임대료
- 유틸리티(전기/수도) 2곳 — 주사위 합 × 계수
- 세금 타일 (소득세·사치세)
- 색상 그룹 독점 시 임대료 2배 + 건물 건설 해금 + 균등 건설 규칙
- Community Chest 덱 (chance와 별개, 16장)
- 저당(Mortgage) — 구매가 50%, 해제 시 × 1.1
- 시작점 보너스 $200
- 경매(Auction)는 기본 OFF, 필요 시 토글

이거 수락/수정/거절 피드백 주면 각 항목 세부 문서화.

## 순서대로 만들 계획 (AI·로봇과 완전 분리)

| 단계 | 범위 | 외부 FastAPI 필요? |
|---|---|---|
| **M0** | 빈 껍데기 + `docker compose up` → `/api/health` OK | 없음 |
| **M1** | Board 3 (빈 12칸 보드) headless E2E — 수동 주사위로 승리 판정까지 | 없음 |
| **M2** | Board 1 돈/땅/건물/임대료/chance 규칙 + 수동 UI | 없음 |
| **M3** | **Board 2 풀 규칙** (감옥·역·유틸리티·세금·독점·커뮤니티체스트·저당) — `pytest` 전수 통과 | **없음** |
| **M4** | 카메라 영상 붙이기 (게임과 독립) | 없음 (ROS 2 카메라만) |
| **M5** | 주사위·말 pick-and-place FastAPI 연결 | 3번 (로봇) |
| **M6** | Whisper FastAPI 연결 | 1번 (STT) |
| **M7** | Gemma 4 FastAPI 연결 | 2번 (LLM) |
| **M8** | (선택) Chance 카드 아트 + Isaac Sim 연동 | Isaac (선택) |

즉 **M0~M4까지는 다른 팀을 기다리지 않아도 된다.** Board 2 풀 규칙도 여기 포함된다.
M5~M7은 서로 독립적이라 어떤 순서로든 통합해도 된다. 통합되지 않은 외부 서비스는 수동 모드가 계속 책임진다.

## CI/CD — PR 올릴 때마다 자동 검증

GitHub Actions 워크플로(`/.github/workflows/movensys-monopoly.yml`)가 PR마다 돌면서 **AI·로봇 없이도** 다음을 자동 확인한다.

1. **Python 문법 체크** — 모든 `.py` 파일이 깨지지 않았는지
2. **앱이 뜬다** — `uvicorn`으로 서버 기동 후 `/api/health`가 200 응답
3. **스텁 모드 동작** — 환경변수(Whisper/Gemma/로봇 URL) 전부 비어 있어도 `/api/robot/health`가 `{"mode": "stub"}` 리턴
4. **Board 3 스모크 테스트** (M1부터) — 수동 주사위 입력으로 한 바퀴 → 승자 판정
5. **Board 1 규칙 테스트** (M2부터) — 매입·건설·임대·파산
6. **Board 2 규칙 테스트** (M3부터) — 감옥·역·유틸리티·세금·색상 독점·커뮤니티체스트·저당

**핵심:** CI 환경에는 Whisper·Gemma·로봇 FastAPI가 **하나도 기동되지 않는다**. 그래서 CI가 통과한다는 것은 곧 "외부 서비스 없이도 게임이 완전 동작한다"는 증거다.

마일스톤 단계는 워크플로 env `MONOPOLY_MILESTONE`으로 제어된다. 각 마일스톤이 끝나면 값을 올리고, 해당 테스트가 빠져있으면 CI가 실패로 바뀐다 (회귀 방지).

로컬에서 같은 검사를 돌리려면:
```bash
cd movensys-monopoly
./scripts/ci_local.sh
```

자세한 명세는 원문 PRD §12 참조.
